# Free Pixel Games

A retro arcade web portal featuring **19 free, browser-based HTML5 pixel games** built with pure HTML5 Canvas, Vanilla JavaScript, CSS3, and Web Audio API — no frameworks, no downloads, and instant play.

## Features

- **20 Playable Retro Arcade Games** across Action, Arcade, Shooter, Puzzle & Merge, and Classic & Board categories
- **Live Search & Category Filters** with keyboard shortcuts (`/` or `Ctrl+K` to search, `Esc` to clear)
- **Procedural Web Audio SFX** and custom pixel-art canvas visuals
- **Responsive Design** — playable on desktop, tablet, and mobile
- **Zero Dependencies** — ready for static hosting (e.g., GitHub Pages, Netlify, Vercel)

## Running Locally

Simply open `index.html` in any modern web browser, or serve the folder with any static HTTP server:

```bash
npx serve .
```
